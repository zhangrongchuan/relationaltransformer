# 实验二报告：RowGraphNet（行级条件传播骨干）

日期：2026-07-17 ｜ 状态：原型阶段完成，3 波共 31 个训练 run
对照基线：RT-scratch（22M 参数、50k 步、同任务混合、同 leave-db-out 协议）
driver-dnf val 0.676 / test 0.749、无标签 val 0.366；study-outcome test 0.542。

## 〇、实验设置（对齐 RT 的 example_pretrain.py = 论文 "No" 列 zero-shot）

**协议 = leave-database-out 从零预训练**，逐项复刻 RT [example_pretrain.py](../../scripts/example_pretrain.py)：
- 评测 rel-f1/driver-dnf 时，**整个 rel-f1 库在训练时不出现**（含 driver-top3/
  position），训练集 = 其余 6 库全部任务 `[t for t in all_tasks if t[0]!=db]`，
  评测任务保持严格 zero-shot。对应 [rowgraph_train.py](rowgraph_train.py) main()。
- 从零随机初始化；lr=1e-3 + OneCycleLR(pct_start=0.2, linear)；wd=0.1；
  batch=32；max_bfs_width=256。以上与 RT pretrain 完全相同。
- 每 checkpoint 四种评测：val/test × 正常/无标签（self_label_dropout=1.0）。

**对照基线 RT-scratch**：同协议同步数（50k）从零训练的 22M RT
（[exp1 train_variant.py](../exp1_rt_components/train_variant.py) scratch 模式）。

**两个刻意的差异**：① seq_len=2048（RT 用 1024）——按行建图需更多 cell 凑够
行数（覆盖率实验依据），非等 context 但 RowGraphNet 参数 1/10、快 2×，等步数
下墙上时间更短；② 每次 leave-db-out 只评一个任务（RT 一次评该库全部任务）。

## 一、模型

行=节点、PK-FK=边；行内 cell 编码池化成行向量（RT 编码器可热启动）；
行间带类型消息传递（f2p/p2f/label 三类边），seed 标记条件化；候选值节点
（True/False=布尔编码器，回归=33 个 z 空间分桶+two-hot 期望读出）；label 边
单向流入候选节点（结构化 ICL）。2.05M 参数（RT 的 1/10）。训练吞吐 10.75
it/s（RT 4.85）。图从标准 cell batch 在线构建（采样器零改动，seq_len=2048）。

## 二、模块证明（20k 步，driver-dnf，去掉某模块后 val 的变化）

| 模块 | val 掉幅 | 判定 |
|---|---|---|
| 行间消息传递 | **-20.0**（0.731→0.531，近随机） | 必要 |
| label 边（结构化 ICL） | **-14.6** | 必要 |
| Δt 时间编码 | **-4.5** | 有效（POSTRA 结论复现） |
| RT 编码器热启动 | val -0.9 / 无标签 **+13** | ⚠️ 负资产（见 §4.2） |

## 三、主结果（50k 步，多 seed，联合选点=val_normal+val_noself）

### driver-dnf（3 seeds，mean±std）

| 配置 | test | 无标签 test | 备注 |
|---|---|---|---|
| RT-scratch（对照，22M） | 0.749 | ~0.37 | val 0.676 |
| RGN no_warm | **0.777±0.007**（val-only 选点） | 0.43-0.67 不稳 | 正常成绩最稳赢家，val 0.750±0.006 |
| **RGN dropE09_no_warm** | **0.767±0.035** | **0.750±0.025** | 鲁棒性头牌；正常+鲁棒双达标 |
| RGN attn_dropE09_no_warm | 0.759±0.014（3 seeds） | 0.680±0.076 | 确认完：test 更稳但 noself 不如 dropE09_no_warm，**不采纳为最终配置** |

### 泛化点（user-repeat，单 seed）

no_warm：test 0.723 / 无标签 0.644——从零 2M 模型接近 RT 官方续训的 0.734，
无标签更好（0.644 vs 0.624）。

## 四、机制发现（论文素材）

1. **抄标签是随训练逐步学会的**：每个 eval 点同时记录 normal+noself，
   两条曲线随训练分叉——早期 checkpoint 是"结构推理者"（noself 0.64-0.78），
   后期变"标签鹦鹉"（0.38-0.43）。防捷径（dropE09）+联合选点可稳定捕获
   推理者阶段。
2. **捷径偏见通过热启动权重迁移**：RT 编码器权重热启动的模型无标签成绩
   显著更差——偏见随权重进口。与实验一"捷径不可事后拆除"互为印证。
3. **联合模型选择标准**（val_normal+val_noself，纯验证集）：把 seed 间
   无标签方差从 ±0.10 压到 ±0.025，是零成本的稳定化手段。

## 五、诚实的未解决项

- **study-outcome（0 标签纯结构任务）**：宽行稀释假设被 attention pooling
  实验排除（没解锁）；2M/50k 规模下所有方法（含 RT）都在随机附近。
  重新归因：容量/数据规模不足，或需要 relation-graph 条件化（ULTRA 的
  h2h/h2t 模块，未实现）。fine-tune 后 RT 能到 68.2 说明信号存在。
- **test 方差大**（n=702 小任务 + 采样随机性）：联合选点缓解但未消除；
  论文级结论需要 5+ seeds 或更大任务验证。
- 官方完整规模 RT（0.802）仍略高于我们最好的 0.767±0.035——完整规模
  的 RowGraphNet 训练是下一个大实验。

## 六、后续实验结果（2026-07-17 更新）

### 6.1 上下文缩放实验：2048 饱和（重要负结果）

推理探针（2048 模型喂更大图）：完全平坦。训练缩放（4096/8192/10240 各自
训练 50k 步）：**没有任何尺寸超过 2048 基线**，普遍略降。20480 被叫停。
结论：rel-f1 有用上下文 ~400 行即饱和，多余预算是 BFS 随机尾部的噪声。
新骨干的优势是"同上下文学得更好"（val +7~8）而非"读得更多"；完整规模
的投入方向是容量/步数/数据/更聪明的采样，不是更大 context。

### 6.2 关系图（ULTRA h2h/h2t/t2h/t2t）：val 稳定提升，确认采纳

实现：每子图微型关系图（关系=(子表,父表)对，四种交互连边），seed 查询
关系 boundary 初始化，2 层传播调制主图 FK 消息，零初始化投影（初始与无
关系图模型逐位等价）。+0.73M 参数。

driver-dnf 三 seed：val **0.764±0.003**（全项目最高且最稳；no_warm
0.750±0.006，+1.4 约 2σ+）；test 0.772±0.027（持平 no_warm 的 0.777）；
单点最高 **0.809**（首次超官方完整 RT 的 0.802）。
study-outcome：无效（归因链完结：该任务需要语义/世界知识而非结构——
论文表中仅 LLM 系方法略超随机，为 scoping 结论）。

### 6.3 完整规模结果（d512 × 100k，最终版）

（表示法：最高值加粗，括号列出全部 seed 逐个值——不隐藏方差）

| 配置 | test 最高（各seed） | 无标签最高（各seed） | 判定 |
|---|---|---|---|
| **relgraph_no_warm_d512** | **0.820**（0.820/0.803） | 0.702（0.702/0.455）| **分数王：两 seed test 均 ≥ 官方 RT 0.802；无标签依 seed 波动** |
| relgraph_dropE09_no_warm_d512 | 0.714（0.714/0.688）| 0.578（0.546/0.578）| dropout 不受益于扩容，反而变差 |
| dropE09_no_warm（d256 原型）| **0.801**（0.801/0.782/0.718）| **0.784**（0.740/0.726/0.784）| **鲁棒王：无标签三 seed 全部 > 官方 RT 的 0.623（最低 0.726）** |

**容量缩放判定**：对"分数"配置有效（relgraph_no_warm 0.772±0.027@d256
→ 0.811±0.008@d512，更高且更稳）；对"鲁棒"配置（dropE09）无效反而有害。

### 6.4 官方 RT 的无标签锚点 + 稳定性的精确归因

补测官方 pretrain ckpt 换 6 个采样 seed：正常 0.731±0.006、
**无标签 0.623±0.002（极稳）**——证明 (a) 无标签指标本身不噪；
(b) 充分训练的官方 RT 有一定结构推理力（0.623 >> RT-scratch 的 0.37）。

稳定性的精确归因（修正早前过宽的"不稳"结论）：
- **带 dropE09 的配置无标签是稳的**（0.750±0.025）——dropout 阻止了
  "鹦鹉化转变"，模型全程处于结构推理域，选点不敏感；
- **不带 dropout 的配置无标签不稳**（no_warm ±0.033~0.123）——训练中会
  发生鹦鹉化，选点必须撞上早期窗口，小 val（566）选不准。

### 6.5 上下文缩放最终闭环

driver-dnf（4096/8192/10240 均不敌 2048）+ **user-repeat@8192 也否定**
（0.712 < @2048 的 0.723，预算饥饿任务同样饱和）。结论普适：瓶颈不是
上下文量，2048 cells（~400 行）已饱和。

## 七、最终结论（Pareto 两极 + 一个开放问题）

1. **分数极**：relgraph_no_warm_d512 = **test 0.811±0.008**，从零 100k 步、
   5M 参数（官方 RT 22M 的 1/4），稳定达到/微超官方完整规模 RT。
2. **鲁棒极**：dropE09_no_warm_d256 = **无标签 0.750±0.025**，三 seed 全部
   超过官方 RT 的 0.623——结构推理能力代际领先，且因 dropout 而稳定。
3. **两极目前不可兼得**（分数王无标签平庸、鲁棒王 test 略低）——
   score-robustness 权衡是清晰的开放问题；dropout 强度/日程（如退火）
   是最直接的下一步。
4. 缩放定律：上下文缩放无效（饱和）；容量缩放只惠及分数极。
5. 机制三连（跨规模复现）：抄标签随训练渐进形成；热启动进口捷径偏见
   （full/dropE09+warm 全线更差）；防捷径必须从起点。
